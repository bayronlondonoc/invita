# Carta

Una sola página: cartel → sobre → hojas → final. HTML, CSS y JS puro.

Para poner las hojas: copia las fotos en `fotos-originales/` (hoja-01.jpg, hoja-02.jpg…) y corre
`python3 scripts/convertir.py`. Crea `hojas/` y `hojas/mini/` en WebP y actualiza `HOJAS` en `assets/carta.js`.
Las originales no se suben al repositorio.
